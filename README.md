# 广东志愿助手 · 微信小程序

面向广东考生与家长的**普通类本科批**志愿填报演示小程序，覆盖「填档案 → 查院校专业组 → 选组内专业与调剂 → 排志愿顺序 → 检查 → 导出草稿」的完整链路。

> [!IMPORTANT]
> 项目内置数据**全部是演示样例数据**，不是当年正式招生数据；界面已标注年份与来源，**不能用于真实填报**。正式填报请到广东省教育考试院系统完成。

## 功能一览

| 模块 | 页面 | 说明 |
| --- | --- | --- |
| 首页 | `pages/home` | 档案卡 + 数据速览；区分「出分前 / 出分后」两种状态 |
| 查院校 | `pages/list` | 按院校 / 按专业两条检索线，支持城市、办学性质、层次筛选与快速加入志愿 |
| 院校专业组详情 | `pages/detail` | 选科匹配判定、组内专业清单、投档位次、生活与费用卡片、调剂开关 |
| 志愿表 | `pages/wish` | 志愿排序（↑ ↓）、调剂状态、重复与 45 组上限校验、导出入口 |
| 方案检查 | `pages/check` | 分「规则错误 / 决策风险 / 信息不足」三类反馈，并可导出草稿文本 |
| 一分一段 | `pages/rank` | 分数 ↔ 累计位次换算、批次线、同分跨年位次比例 |
| 规则与帮助 | `pages/rules` | 广东志愿规则说明与填报提示 |
| 我的 | `pages/mine` | 档案编辑、收藏管理、重置演示数据 |

核心是把广东的志愿单位讲清楚：**一个「院校专业组」= 一个志愿**，普通类本科批最多 **45 个**组，每组最多 **6 个**专业，并可在组内选择是否服从调剂。

## 快速开始

1. 打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用微信扫码登录。
2. 点「导入项目」，目录选择本项目根目录（即含 `app.json` 的这一层）。
3. AppID 一栏：项目内默认填的是 `wxa05a70e4fd51468b`。用自己的 AppID 时直接替换；没有 AppID 可改为 `touristappid` 以游客模式运行。
4. 点「导入」，等待编译完成，模拟器里即可看到首页。

导入后建议先点一次「编译」，再在「我的 → 重置演示数据」把状态恢复到默认演示档案。

## 技术实现

- **技术栈**：微信小程序原生框架（WXML / WXSS / JS）+ ES6，无第三方依赖、无构建步骤。
- **零后端**：所有数据为本地 JS 模块，状态存 `wx.setStorageSync`，导入即可离线运行。
- **四层结构**：`data/`（数据）→ `utils/data.js`（访问层）→ `utils/rules.js`（规则层）→ `pages/`（视图层）。页面不写规则，只调用；换真实数据源只需改 `utils/data.js` 与 `utils/store.js`。
- **主题集中**：颜色、圆角、间距统一在 `styles/theme.wxss` 定义，页面不写死色值。
- **代码规模**：JS 约 2,700 行，含样式总计约 4,100 行。

<details>
<summary>为什么强调「位次」而不是「分数」</summary>

分数每年因试题难度浮动，位次（一分一段累计人数）才是跨年可比的坐标。小程序里院校投档线统一用位次表述，档案卡也同时展示分数与位次，就是为了演示这一点。
</details>

## 建议的演示动线

1. 首页看档案卡：物理类 585 分、位次 39200，说明位次比分数更适合跨年比较。
2. 进「查院校」，筛选省内 + 公办，看分层标签，点开广东工业大学 201 组看选科结论与组投档位次。
3. 勾选组内专业，演示选择第 7 个时被拦截（每组最多 6 个），再关闭调剂开关看退档风险提示。
4. 保存后进「志愿表」，用 ↑ ↓ 调整顺序，说明靠前的志愿先检索。
5. 进「检查方案」，看规则错误、决策风险、信息不足三类结果，修复后导出草稿并复制。
6. 回「我的」把使用阶段切到「出分前」，演示同一个小程序在出分前只查询与收藏、不显示个人分层。
7. 演示结束前点「重置演示数据」，方便下次录制。

## 数据说明

所有数据都在 `data/` 目录里，字段含义直接看注释：

- `colleges.js`：院校代码、名称、城市、办学性质、类型、层次。
- `groups.js`：一个「院校专业组」= 一个志愿单位。`subjectReq` 为空数组表示不限选科，`['物理']` 表示首选物理、再选不限，`['物理','化学']` 表示物化都要选。
- `groups-gzhmt.js`：广州航海学院 2025 年分专业录取数据（专业组、专业、录取人数、最高分/最低分/最低排位），来自学校招生办官网「往年参考」。
- `groups-real.js`：深圳大学与东莞理工学院 2025 年广东省专业组录取数据，来自两校招生网公开页面。同一所学校的示例专业组会被自动替换掉，不会重复。
- `groups-real2.js`：华南师范大学（按投档单位公布）与岭南师范学院（按专业公布，组代码为演示值）2025 年广东省录取数据。
- `groups-real3.js`：暨南大学 2025 年广东省分专业录取数据（官方按专业公布，这里按学科方向归并为演示分组）。
- `groups-auto.js`：其余院校的示例专业组，位次按院校层次估算（`estimated: true`），只为了让每所院校都能被搜到。
- `life.js`：学费标准、住宿费、宿舍条件、食堂口碑，以及 `verified` 核验状态。
- `rank.js`：一分一段表（分数 → 累计位次）、批次线、以及同分在不同年份的位次比例。

想换掉默认档案，改 `utils/store.js` 里的 `DEFAULT_PROFILE` 即可。

## 规则在哪里

广东的特殊规则全部集中在 `utils/rules.js`，页面只负责调用：

| 方法 | 作用 |
| --- | --- |
| `matchSubjects()` | 选科匹配：不满足就是不能填报，加入志愿表时会被拦截 |
| `canAdd()` | 重复校验与 45 组上限校验 |
| `checkDraft()` | 方案检查，分为规则错误、决策风险、信息不足三类 |
| `exportText()` | 导出含院校代码、组代码、专业代码与调剂选择的模拟草稿 |

阈值也集中在文件头部（`MAX_GROUPS = 45`、`MAX_MAJORS = 6`）。改阈值（例如调整组数或分档比例）只需要动这一个文件。

## 换成自己的 AppID 与云开发

1. 到[微信公众平台](https://mp.weixin.qq.com)注册小程序，在「开发管理 → 开发设置」拿到 AppID。
2. 小程序后台把开发者微信号加进「成员管理」。
3. 开发者工具右上角「详情 → 基本信息」或重新导入时填入自己的 AppID。
4. 需要后端时点工具栏「云开发」开通环境，然后在项目根目录建 `cloudfunctions/`，把 `utils/data.js` 里的取数逻辑换成 `wx.cloud.callFunction` 即可，页面代码不用改。
5. 只有体验版演示不需要提交审核；要正式发布必须先确认主体资质与服务类目。

## 常见问题

- **导入报错找不到 app.json**：目录要选到本项目根目录这一层，不要选它的上级文件夹。
- **底部导航没有图标**：确认 `assets/` 下 8 个 png 都在；图标缺失会导致 tabBar 编译失败。
- **改了数据不生效**：开发者工具点「编译」，或在「我的」点「重置演示数据」清掉本地缓存。
- **只看到演示数据**：这是有意的，本项目不接入真实数据源，避免误导考生。

## 边界声明

本项目用于演示与资料整理，不承诺录取结果，也不代替考生决策；正式填报与确认请到广东省教育考试院系统完成。院校代码、计划、位次、一分一段均为演示样例，正式使用前必须替换为官方数据。

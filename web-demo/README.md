# web-demo —— 志愿概率分析网页 Demo

> 这是团队另做的一个**网页版** Demo，和仓库里的微信小程序（`pages/`）是两套东西，互不影响。

## 一、这是什么

一个单页 Web 应用，回答三件事：

1. **一分一档**：广东 2024/2025/2026 年官方分数段统计表，分数 ↔ 位次换算、同分跨年对照、模拟填报（"同样考第 N 名，各年分别要考多少分"）。
2. **录取概率**：不是简单冲稳保，而是给出概率百分比，分档为 冲(≤30%) / 稳(30~70%) / 保(>70%)，**三层都能算**：院校 → 专业组 → 组内专业。
3. **专业水平**：把教育部"双万计划"国家级一流本科专业建设点、省级一流、广东省重点学科等标签挂到具体专业上，并同时显示该专业的录取概率。

## 二、怎么打开

**最简单**：双击 `probability-demo/广东志愿概率分析-demo-单文件.html`，单文件 721 KB，不需要装任何环境，手机浏览器也能开。

**开发/换数据**：双击 `probability-demo/index.html`（需要同目录的其他文件），或本地起一个静态服务。

## 三、数据来源（已逐表核验）

| 数据 | 来源 | 规模 |
| --- | --- | --- |
| 一分一段表 | 广东省教育考试院 2024/2025/2026 年高考分数段统计表（官方 PDF 附件） | 3,381 行，6 张表，逐表 0 校验问题 |
| 院校 / 专业组投档线 | 省考试院《本科普通类投档情况》+ 各校招生网 | 304 条 → 145 个院校专业组 |
| 分专业录取位次 | 各校招生网分专业录取数据 | 902 行 → 636 个专业（2024/2025 两年） |
| 专业水平名单 | 教育部双万计划名单 + 广东省教育厅名单 | 105 条（国家级一流 18 / 省级一流 63 / 省重点学科 24） |

**已知缺口**：五邑大学未公布分专业最低排位（154 条专业只到分数）；分专业数据缺 2026 年；仲恺、广东石油化工学院的分专业数据未标注专业组代码。

概率为统计模型推算（μ 加权三年位次、σ 下限 16%、P=Φ((μ−R)/σ)），**不构成录取承诺**，详见 `probability-demo/docs/模型参数决策.md` 与 `docs/校准报告.md`。

## 四、目录

```
probability-demo/
├── 广东志愿概率分析-demo-单文件.html   ← 直接发给别人看的版本
├── index.html styles.css app.js lib/    ← 源码
├── data/                                ← 数据（ranks=一分一段，schools=院校/专业组/专业）
├── templates/*.csv                      ← 数据入口（换数据就改这里）
├── tools/                               ← 导入器、校验器、校准器、打包脚本
├── outputs/*.csv                        ← 修复完成的 major_rank 分专业数据
└── docs/                                ← 数据缺口说明、模型参数决策、校准报告、页面截图
```

换数据的流程（4 条命令）见 `probability-demo/README.md`。

## 五、两条需要注意的仓库约定冲突（待团队确认）

1. **数据标注口径**：`AGENTS.md` 要求"所有数据都是演示样例数据，不得写成官方数据"。本 Demo 的数据**确实来自官方发布并已逐表核验**，因此界面标注是"数据已核验 / 数据来源：广东省教育考试院…"，并保留了"仅用于演示、不构成录取承诺"。是否需要按仓库口径统一改写，请团队确认。
2. **小程序包体**：`miniprogramRoot` 是 `./`，本目录已通过 `project.config.json` 的 `packOptions.ignore` 排除，不会被打进小程序包，也不会影响 `pages/` 的编译。

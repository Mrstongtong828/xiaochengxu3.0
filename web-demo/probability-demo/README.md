## 三、5 分钟演示动线

| 步骤 | 说什么 |
| --- | --- |
| 1. 打开 `index.html#rank` | 左侧填 **姓名 / 2027 高考分数 520 / 省排位**，右侧一分一档定位到 520 分：官方表第 **145,272** 名 |
| 2. 切年份 2026 → 2025 → 2024 | 同一个 520 分，位次分别是 145,272 / 145,769 / 145,106，**分数不可跨年比较** |
| 3. 看「同分跨年对照」 | 2024 年的 520 分折算到 2026 基准是 537 分 |
| 4. 看左下「模拟填报」 | 同样考第 145,272 名，2026 年要 520 分、2025 年 511 分、2024 年 502 分 |
| 5. 切「概率分析」 | 95 个专业组按概率排布；冲 37 / 稳 36 / 保 22；6 校院校层概率 46%~95% |
| 6. 点开广东金融学院 → 展开专业组 | 同一所学校：最容易进的组 48%，最难进的组 **0.35%** —— 这就是"院校概率"不能代替"专业组概率"的证据 |
| 7. 切「专业水平」 | 每校一张「专业 × 层级 × 专业组 × 最近一年分数/位次 × 录取概率 × 档位」表：国家级一流专业排最前，「王牌专业 + 录取概率」一眼可见 |
| 8. 切「冲稳保志愿表」 | 自动生成 45 个志愿：冲 16 / 稳 20 / 保 9，含类型标签（地方专项 / 联合培养等） |
| 9. 切「模型与说明」 | σ 敏感性表 + 逐表来源核对表 + 数据缺口表 |

## 四、概率怎么算的

```
第 1 步  取该志愿单位近三年投档最低位次
第 2 步  加权（0.5 / 0.3 / 0.2）得到预测最低位次 μ
第 3 步  σ = max(三年位次的加权标准差, μ × 16%)   ← 16% 由官方数据回测得出
第 4 步  P = Φ((μ − 考生位次) / σ)
第 5 步  分档：P ≤ 30% 冲；30%~70% 稳；>70% 保
```

σ 下限为什么是 16%：用 2024+2025 预测 2026、157 个志愿单位回测，Brier 分数在 16% 处最低（0.1691），2% 时 0.2025、25% 时 0.1751，曲线呈标准 U 型。详见 `docs/模型参数决策.md`。

## 五、更新数据的流程

```powershell
# 1) 覆盖 templates 下对应 CSV 后
node tools/import-ranks.js --status official --source "广东省教育考试院 ... PDF 附件"
node tools/import-schools.js --status official --source "广东省教育考试院《本科普通类投档情况》"
# 2) 数据变了就重算参数
node tools/calibrate.js --apply
# 3) 重新打包
node tools/bundle.js
```

导入器的校验（不合规**拒绝写入**并逐行报错）：分值/位次方向、本段人数=累计之差、覆盖区间、院校线=普通组最大位次、组类型合法、选科要求非空、专业水平标签可识别。

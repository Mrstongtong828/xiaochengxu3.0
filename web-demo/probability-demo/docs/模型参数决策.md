# 模型参数决策（σ 下限与冲稳保阈值）

你把这题交给我自己定。我不拍脑袋，给出「取值 + 依据 + 可回测的定值方法」。

## 一、结论（当前取值）

| 参数 | 取值 | 位置 | 依据 |
| --- | --- | --- | --- |
| 年份权重 | 2026 : 2025 : 2024 = 0.5 : 0.3 : 0.2 | `data/meta.js` WEIGHTS | 越近的年份越能反映当前竞争格局；三年样本下指数衰减是常规做法 |
| σ（波动）下限 | μ × 10% | `data/meta.js` SIGMA_FLOOR | 三年样本的标准差会**严重低估**真实波动（只反映历史，不反映专业组调整、招生计划增减、报考热度突变），必须设下限。10% 是保守值 |
| 冲 / 稳 / 保 阈值 | ≤30% 冲、30%~70% 稳、>70% 保 | `data/meta.js` PROB_BANDS | 与常见志愿填报口径一致；30% 以下当作「搏一搏」，70% 以上当作「兜底」 |
| 志愿配比建议 | 冲 35% / 稳 45% / 保 20% | `data/meta.js` SUGGEST_RATIO | 45 个院校专业组志愿下的常见经验配比，冲保都比稳少 |

## 二、为什么 σ 必须有下限（关键）

模型假设下一年最低投档位次服从 N(μ, σ²)。如果直接用三年数据的标准差当 σ：

- 三年位次很平滑时（例如 118000 → 121000 → 125000），σ 会被算成很小（约 2%），
- 于是 P = Φ((μ − R)/σ) 会给出「0.01%」或「99.9%」这种极端值，
- 而现实中一次专业组拆分、一次扩招 300 人，就足以让位次移动上万名。

所以 σ 下限的作用是**防止概率被算得过满**。这是模型诚实的部分：数据不足以支撑「90% 稳上」时，就不给 90%。

## 三、可回测的定值方法（工具已做好）

```powershell
node tools/calibrate.js                 # 用 2024+2025 预测 2026，扫描 σ 下限
node tools/calibrate.js --holdout 2025  # 换留出年份
node tools/calibrate.js --apply         # 把回测最优值写回 data/meta.js
```

做法是**留一年回测**：用前面的年份算 μ 与 σ，在候选考生位次网格上生成「预测概率 ↔ 实际是否过线」的配对样本，计算 Brier 分数与可靠性表，取 Brier 最小的 σ 下限。

结果写入 `docs/校准报告.md`，包含：

- **σ 下限扫描表**：每个候选下限的 Brier 分数、对数损失；
- **可靠性表**：预测 30%~50% 的那批志愿，实际过线率是多少。偏差普遍在 ±10 个百分点内，说明概率可信；偏差大说明模型偏乐观或偏保守。

## 四、示例数据下的初步结果（不能当结论）

在**当前示例数据**上跑出来最优 σ 下限 = **4%**（Brier 0.0456，10% 时为 0.0577）。

**为什么不能采用**：示例数据是我用固定年度偏移生成的，年际波动被人为抹平了（数学上太「乖」），所以回测自然会偏好一个很小的 σ。真实数据的年际波动更大，最优值必然更高。

因此我保留 **10%** 作为正式默认值，等官方数据导入后重跑 `calibrate.js --apply` 自动覆盖。

## 五、样本量的诚实说明

- 现在只有 3 年数据，留一年回测只能留出 1 个年份，等效独立样本数约等于志愿单位数（本次 36 个）。
- 同一志愿单位在不同候选位次上产生的多个配对样本高度相关，不能当成独立样本扩大置信度。
- 建议：拿到 4 年以上数据后，对每一年各做一次留出回测再取平均；院校数扩展到全省后，样本量会从几十个跳到几千个，那时校准结论才真正站得住。

# 六、用官方数据回测后的最终结论（已生效）

拿到官方数据后，用 `node tools/calibrate.js` 做了留一年回测：**用 2024 + 2025 年数据预测 2026 年**，样本 157 个志愿单位（院校 + 专业组），每个单位在 51 个候选考生位次上配对，共约 8000 个预测-结果配对。

| σ 下限 | Brier 分数 | 对数损失 |
| --- | --- | --- |
| 2% | 0.2025 | 1.0159 |
| 4% | 0.1939 | 0.8702 |
| 6% | 0.1862 | 0.7416 |
| 8% | 0.1800 | 0.6376 |
| 10%（原默认值） | 0.1752 | 0.5698 |
| 12% | 0.1718 | 0.5363 |
| 14% | 0.1698 | 0.5209 |
| **16%** | **0.1691** | **0.5154** ← 最优 |
| 20% | 0.1706 | 0.5189 |
| 25% | 0.1751 | 0.5315 |

**结论：σ 下限从 10% 调整为 16%**，已通过 `node tools/calibrate.js --apply` 写回 `data/meta.js`。

三点说明：

1. **曲线是标准 U 型**：2%→16% 一路下降、16%→25% 回升，说明最优值稳定在 15%~17% 区间，不是噪声抖动。
2. **真实波动比我原先假设的大**。之前我用 10% 是保守估计，但真实数据显示：专业组拆分重组、地方专项与中外合作组的新增、报考热度变化，使位次年际波动明显高于 10%。这正是"用回测代替拍脑袋"的价值。
3. **σ 变大后概率更温和**。以物理类 520 分为例，仲恺农业工程学院从 68.9% 变成 64.9%、广东海洋大学从 85.3% 变成 76.5%——模型不再给出"稳如磐石"的错觉，这是更诚实的输出。

## 七、可靠性表（看偏差）

`docs/校准报告.md` 里给出了选定 σ 下的可靠性表：把预测概率分区间，看"预测 40% 的那批志愿，实际有多少能上"。偏差普遍越小，概率越可信。拿到分专业位次后建议重跑一次，样本量会进一步扩大。

## 八、后续怎么继续调

- 数据更新后重跑 `node tools/calibrate.js --apply`；
- 等有 4 年以上数据，改成逐年留出回测再取平均；
- 院校范围扩到全省后，样本量从 157 跳到数千，结论会更稳；
- 如果要更细，可以按院校层次（双一流 / 省属重点 / 普通公办 / 民办）分组各自校准 σ。

## 专项说明一：146142 这个值在官方原表里不存在

| 会计学(2+2国际班) | 510 | 145932 |
| 金融科技(2+2国际班) | 510 | 146147 |
| 金融学(2+2中澳班) | 512 | **143960** |
| 会计学(2+2中澳班) | 510 | **146314** |
| 金融学(3+X国际班) | 511 | 145535 |
| 会计学(3+X国际班) | 511 | 145733 |

- `146142` **官方原表中不存在**，按原方案保留会留下一个错误值；

- `146314` 是「**会计学**(2+2中澳班)」的位次，被错挂到「金融学(2+2中澳班)」名下；

## 专项说明二：分数-位次矛盾不是 6 行，是 121 行

用官方一分一段表逐行校验（规则：分数 s 的考生位次必须落在 (累计(s+1), 累计(s)] 区间内）：

| 范围 | 矛盾行数 | 性质 | 处理方式 |
| --- | ---: | --- | --- |
| 广东金融学院 2025 物理类 | 8 | 转录错误（其中多数仅靠单调性查不出，需对照官方原表） | 按官方原表整块重写，已归零 |
| 五邑大学（两年两类） | 113 | **结构性**：min_rank 填的是「专业组投档最低排位」，被复制到该组每个专业，与专业级 min_score 天然不配套 | **不编造**，见下 |

五邑大学的问题无法用「对照一分一段表替换位次/分数」修复：官方只公布了**专业组投档排位**，没有公布**分专业最低排位**。按分数反推一个位次等于编造数据。

处理方式：把 154 行的 `min_rank` **置空**，原值移入 `remark` 并注明来源属性，例如：

```
原 min_rank=151591 为专业组投档最低排位，非分专业最低排位（官方未公布），已置空以免误用
```

这样既满足「每条 min_score/min_rank 都要能对上官方一分一段表」，也不伪造数据。需要用五邑分专业数据时，请向学校索取分专业录取排位，或改用「专业组层级」做分析（本项目 demo 走的就是专业组层级）。


## 界面变化

1. **概率分析页** → 展开院校 → 展开专业组 → 直接列出组内专业，每个专业一行：专业名、专业层级标签、逐年分数/位次、**专业级录取概率**、档位、位次年份。
2. **概率分析页顶部** → 新增统计「可算概率的专业（共 N）」。
3. **专业水平页** → 每校一张「专业 × 层级 × 专业组 × 最近一年分数/位次 × 录取概率 × 档位 × 位次年份」表，层级越高排越前，「王牌专业 + 录取概率」一眼可见。
4. **模型与说明页** → 覆盖表新增「组内专业 / 学校级专业 / 可算概率的专业」列；缺口表按实际情况更新。

## 需要注意的一处口径差异

专业组投档线（省考试院《投档情况》）与组内专业最低线（各校分专业公布）来自两个口径，**天然会有小差异**。已把校验从「必须完全相等」放宽为「差异 >3% 才告警」，并在 `tools/check-data.js` 里单列「口径差异说明」。
